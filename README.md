# JS Gym 🏋️‍♂️

**JavaScript Practice Platform for Beginners**

JS Gym is a small interactive training platform designed to help beginners practice JavaScript through short, practical coding challenges.

The project uses a **restaurant-themed learning environment** to make programming concepts easier and more engaging to practice.

## Current Version — v1.0

Built with:

* HTML5
* CSS3
* Vanilla JavaScript
* ES Modules
* Responsive Design
* LocalStorage

### Current content

* **Основи** — 10 challenges
* **Масиви** — 10 challenges
* **Функції** — 10 challenges

**30 challenges in total.**

Each challenge includes:

* theory
* progressive hints
* code editor
* code execution
* automated tests where applicable
* solution

The interface also supports:

* Dark / Light theme
* Responsive layout
* Keyboard shortcuts
* Accessibility features
* Initial branded preloader

## Roadmap

JS Gym is planned as a growing learning platform.

### v1 — Vanilla JavaScript

* 30 beginner challenges
* Interactive code practice
* Theory and hints
* Automated testing
* Dark / Light theme

### v2 — React

The next version will rebuild the application with React and expand the learning system with:

* more JavaScript categories
* Objects
* ES6+
* Async JavaScript
* additional challenges
* Ukrainian / English localization
* dedicated theory section
* improved progress tracking

### Future

The long-term goal is to evolve JS Gym into a full-stack learning platform using:

**React → Node.js → Express → MongoDB**

with user accounts, saved progress and a larger learning library.
